* Image acquisition and representation

* Feature detection and analysis

---

## 🔍 **METHODOLOGY / STEPS PERFORMED**

### 🔹 **1. Image Upload & Reading**

* Image uploaded using Google Colab
* Read using `cv2.imread()`
* Image dimensions and channels analyzed

### 🔹 **2. Color Space Conversion**

* BGR → RGB for correct visualization
* RGB → Grayscale for processing

### 🔹 **3. Pixel Matrix Analysis**

* Pixel values printed
* Individual pixel intensity inspection

### 🔹 **4. Edge Detection**

* Canny Edge Detection applied
* Highlights image boundaries

### 🔹 **5. Line Detection**

* Hough Line Transformation used
* Detects straight lines in the image

### 🔹 **6. Blur Detection**

* Laplacian operator applied
* Sharp and blurred regions identified

### 🔹 **7. Masking & Sharp Region Extraction**

* Thresholding and morphology used
* Clear regions isolated using masks

### 🔹 **8. Histogram Analysis**

* Grayscale histogram plotted
* Pixel intensity distribution analyzed

### 🔹 **9. Histogram Equalization**

* Contrast enhancement performed
* Before vs after comparison shown
