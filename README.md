### 🖼️ **Experiment 01: Image Processing Using OpenCV**

📁 Folder: `1. Image-Processing-OpenCV`

This experiment introduces **core image processing operations** using OpenCV.

#### 🔹 Concepts Covered:

* Image acquisition and representation
* Pixel matrix and intensity analysis
* Color space conversion (BGR ↔ RGB ↔ Grayscale)
* Edge detection using Canny algorithm
* Line detection using Hough Transform
* Blur detection using Laplacian operator
* Masking and extraction of sharp regions
* Histogram plotting and analysis
* Histogram equalization for contrast enhancement
